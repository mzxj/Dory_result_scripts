# Dory Manuscript Results and Figures Generation Code
This repository contains the source data and plotting scripts used in the Dory manuscript.

## Repository structure

- `Figure1/` – scripts and data used for Figure 1
- `Figure2/` – scripts and data used for Figure 2
- `Figure3_suppl5_6/` – scripts and data used for Figure 3 and Supplementary Figures 5–6
- `Figure4/` – scripts and data used for Figure 4
- `Figure5_suppl8_9_10_12_13/` – scripts and data used for Figure 5 and Supplementary Figures 8, 9, 10, 12, and 13
- `SuppleFigure1/`, etc. – scripts and data for supplementary figures

## Reproducing the figures

Navigate to the corresponding figure folder and run the R script(s) contained in that folder.

## Data

Data required for figure generation are provided within the corresponding figure directories.
